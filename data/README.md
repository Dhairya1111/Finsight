# Sample Data

FinSight includes demo/sample datasets so the application is usable immediately after cloning.

Included files:
- `transactions_demo.csv` — synthetic personal finance transactions
- `market_demo.json` — bundled demo company fundamentals with bundled price-history snapshots
- `economic_indicators_india.json` — India-focused macro indicator snapshot generated from the World Bank public API
- `nifty50_history_demo.json` — bundled market index history snapshot for event analysis
- `economic_events.json` — curated event metadata and notes
- `credit_risk_demo.csv` — synthetic ML dataset for classification demo

## Important notes

- Demo data is clearly labeled in the application.
- Synthetic datasets are for educational demonstration only.
- Public-data snapshots may become stale over time and can be refreshed with project scripts.
